Как избежать ошибки 404 на GitHub Pages?

Чтобы ваш веб-сайт UPG открывался корректно и без ошибки 404 при публикации на GitHub Pages, соблюдайте важные правила:

  • Имя файла: Основной файл обязательно должен называться index.html и находиться в корневой папке репозитория (root folder).
  • Настройки Pages: В настройках репозитория (Settings → Pages) выберите источник Deploy from a branch, укажите ветку main (или master) и папку /(root).
  • Привязка ссылок: Все пути к картинкам и скриптам должны быть относительными.
  • Публичность: Репозиторий должен быть открытым (Public) для бесплатного GitHub Pages.
